Payment Plan Tracker — Pro
========================================

Thank you for purchasing Payment Plan Tracker Pro!


WHAT'S INCLUDED
----------------------------------------
• Unlimited payment plans
• Full payment schedule with auto-calculated due dates
• Mark payments as collected — next due date auto-updates
• Dashboard with KPIs: active plans, outstanding, collected, overdue
• Status tracking: active, on hold, complete, issue, etc.
• Edit & delete plans anytime
• Export data via browser (localStorage-based)


HOW TO USE
----------------------------------------
1. Open "pro-version.html" in any modern browser (Chrome, Firefox, Safari, Edge)
   — no installation, no server, no internet needed

2. Click "+ New Payment Plan" to create your first plan
   - Enter customer name
   - Enter total amount
   - Select frequency (weekly / biweekly / monthly / quarterly)
   - Enter number of payments
   - Select start date
   - Choose status

3. The app automatically:
   - Calculates the installment amount (total ÷ number of payments)
   - Generates the full payment schedule with correct due dates
   - Tracks progress (paid / total)

4. Mark a payment as "Paid" by clicking the green "Mark Paid" button
   - The next payment date updates automatically
   - The progress bar updates
   - Dashboard KPIs update in real time

5. View the full schedule by clicking the "Schedule" button on any plan

6. All data is saved in your browser (localStorage) — close the tab and come back anytime


TIPS
----------------------------------------
• Use the filter tabs (All / Active / Pending / Complete / On Hold / Issues) to quickly find plans
• The "Free: X/99999" badge is hidden in Pro — you have unlimited plans
• To backup your data: open browser DevTools (F12) → Application → Local Storage → copy the "paymentPlans" value
• To restore: paste it back into the same location
